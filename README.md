# Green Leaf Bistro

Green Leaf Bistro is a restaurant web application built as a continuous web development project.

The project started as a basic HTML/CSS/JavaScript restaurant website and will be progressively developed toward a more complete, production-style full-stack application.

The goal is not simply to finish a website, but to use the project as a practical environment for learning modern web development, software architecture, backend development, databases, security, testing, deployment, and professional development practices.

## Current Status

**Stage:** Level 1 — Basic Frontend

The current version is a static restaurant website with basic JavaScript functionality.

### Current features

* Home page
* Restaurant information
* Menu page
* Food item cards
* Order page
* Order form
* Basic client-side form validation
* Responsive menu grid
* Interactive buttons and hover effects
* Restaurant contact information

## Development Philosophy

This project follows a few principles:

1. **Understand before abstracting.**
2. **Solve real problems before adding technologies.**
3. **Prefer simple solutions when they are sufficient.**
4. **Build features incrementally.**
5. **Validate important data on the server, not only in the browser.**
6. **Prioritize maintainability and understanding over unnecessary complexity.**
7. **Use the project to develop transferable engineering skills.**

The long-term goal is to transform Green Leaf Bistro from a simple frontend assignment into a realistic restaurant application with a properly designed frontend, backend, API, database, authentication, administration, security, testing, and deployment.

The architecture will evolve according to actual requirements rather than following technology trends blindly.
